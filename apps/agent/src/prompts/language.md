Language agent (no LLM). Keeps the reply language in thread state: the user's chosen language when the app sends it, otherwise the script of the message (Tamil, Devanagari, ...) mapped to a language in config/languages.yaml, otherwise English. Replies are drafted in English, translated with Sarvam sarvam-translate:v1 (formal, international numerals) and the number check is re-run on the translation; if any number or time changed, the English text is sent instead. Safety sentences come only from config/phrases, never from translation.
